# @components-kit/storybook-shared

> Centralized styles, documentation themes, and configuration assets for Storybook 10.

`@components-kit/storybook-shared` de-duplicates documentation styles, theme tokens, and configuration across the three Storybook applications:

- `apps/storybook-portal` (Unified Composition Portal - Port 6005)
- `apps/storybook-vue` (Vue 3 Workbench - Port 6006)
- `apps/storybook-react` (React 19 Workbench - Port 6007)

---

## Exports

### Styles

- `@components-kit/storybook-shared/styles/colors.scss`: Shared color variables.
- `@components-kit/storybook-shared/styles/intro.scss`: Styling for `Introduction.mdx` documentation pages.
- `@components-kit/storybook-shared/styles/side-nav-themes.scss`: Side navigation demo themes.
- `@components-kit/storybook-shared/styles/style.scss`: Base preview styling and typography.

### Configuration

- `@components-kit/storybook-shared/config`: Common Storybook configuration parameters and viewport definitions.
- `@components-kit/storybook-shared/preview`: Standard preview defaults and tags.
